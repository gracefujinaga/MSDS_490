## Questions

#### PyTorch is currently a leading machine learning framework, do you think that will change? Given the explosion of LLMs that can translate between programming languages and packages, does it even make sense to learn new frameworks? Please explain your response to both questions.

I think it will change. PyTorch itself was built on other technologies to create a specific tool for the research community. It has expanded much further outside of that, and pushed the field forward but I think other technologies will eventually build on it. Just how PyTorch built on Caffe and Caffe2, I believe a new framework will eventually build on PyTorch and that history will repeat itself. It could be geared more toward cloud deployment or speed of computation. As the field changes and grows, the technologies that will be used will also change. 

With that said, it definitely makes sense to learn new frameworks. Understanding the fundamentals behind these frameworks means you can better build, optimize, and apply new models. Each framework may be best at different things, and understanding the differences across them and when to best use a different framework in a different place is essential. This might be because of a pre-existing tech stack or run time goals. It could be specific to a dataset or concept.
